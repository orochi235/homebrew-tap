# homebrew-tap

Homebrew formulae for:

- [perch](https://github.com/orochi235/perch) — generate a macOS menu bar app from a YAML file
- [slopboard](https://github.com/orochi235/slopboard) — a wall for AI-generated renders that forgets them unless you pin one

```
brew install orochi235/tap/perch
brew install orochi235/tap/slopboard
```
