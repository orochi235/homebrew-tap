# homebrew-tap

Homebrew formulae for:

- [alpo](https://github.com/orochi235/alpo) — serve a library from its local checkout until a release carries what you need
- [hued](https://github.com/orochi235/hued) — change terminal colors declaratively by directory
- [kouhai](https://github.com/orochi235/kouhai) — a ledger of what Claude Code sessions owe you: questions, and instructions not yet carried out
- [perch](https://github.com/orochi235/perch) — generate a macOS menu bar app from a YAML file
- [transom](https://github.com/orochi235/transom) — a wall for AI-generated renders that forgets them unless you pin one

```
brew install orochi235/tap/alpo
brew install orochi235/tap/hued
brew install orochi235/tap/kouhai
brew install orochi235/tap/perch
brew install orochi235/tap/transom
```
